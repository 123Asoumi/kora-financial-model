# Empreinte SHA-256 du certificat de la clé officielle de KORA-lite (une seule clé pour toutes les versions).
# Ce n'est pas un secret : c'est la « carte d'identité » publique de la clé.
# Coller ici l'empreinte SHA-256, sur une ligne sans « # » : celle affichée par le workflow « Publier une version »,
# ou celle donnée par : keytool -list -v -keystore kora-lite.jks -alias kora-lite  (ligne « SHA256: »).
# Les deux formats sont acceptés. Ensuite, toute APK signée avec une autre clé sera refusée.
